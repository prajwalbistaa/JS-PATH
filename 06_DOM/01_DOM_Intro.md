# DOCUMENT OBJECT MODEL (DOM)

DOM represents the structure of an HTML document as a tree of objects. 
It allows JavaScript to interact with and modify the content and elements of a webpage dynamically.
- By using the DOM, JavaScript can access and manipulate HTML elements, attributes, and styles.
- DOM manipulation enables updating the content, structure, or styling of a page without reloading the webpage.

## Accessing Elements

- getElementById() - Retrieves an element by its id.
- getElementsByClassName() - Returns a collection of elements with a specified class.
- getElementsByTagName() - Selects elements by their tag name.
- querySelector() - Returns the first element matching a CSS selector.
- querySelectorAll() - Returns all elements matching a CSS selector.
